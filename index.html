Install SEOPub

Publish SEO articles and product updates to your store straight from a Google Sheet. It works in your browser's sidebar, using the dashboard you're already logged in to.

SallaZid

Firefox

Firefox 128 or newer. Updates install on their own.

Add to Firefox 340 KB

  1. Click Add to Firefox above.
  2. Firefox says it prevented this site from asking you to install software. Click Continue to Installation.
  3. Click Add. SEOPub is signed by Mozilla, so Firefox installs it without any extra settings.
  4. Click the SEOPub icon in the toolbar to open the sidebar. If you don't see it, it's under the puzzle piece icon, where you can pin it.

Updates

Firefox checks for a new version about once a day and installs it for you. To check right away, open about:addons, click the gear icon, then Check for Updates.

Chrome

Chrome 116 or newer. SEOPub isn't on the Chrome Web Store yet, so it's added in developer mode.

Download for Chrome 329 KB zip

  1. Unzip the download into a folder you'll keep, for example Documents/SEOPub. Chrome runs SEOPub from that folder, so don't delete or move it later.
  2. Open a new tab and go to chrome://extensions. Chrome doesn't let websites link there, so paste it into the address bar.
  3. Turn on Developer mode in the top right corner.
  4. Click Load unpacked and choose the unzipped folder, the one that contains manifest.json.
  5. Click the puzzle piece icon in the toolbar and pin SEOPub. Clicking it opens the side panel.

Updates

Download the new zip and unzip it into the same folder, replacing the old files. Then click the reload arrow on SEOPub's card in chrome://extensions. Your saved settings stay, as long as the folder stays in the same place.

Before your first run

  1. Open your Salla or Zid dashboard, log in, and refresh the tab once so SEOPub can use your login.
  2. Share your Google Sheet and every doc in it as Anyone with the link can view.
  3. Start with two or three rows, check them in your dashboard, then run the rest.
